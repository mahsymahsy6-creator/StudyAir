## 6. Compilation Workarounds

1. **`tsc` Command Flags for `dist-test` Generation**:
   - Running `npx tsc <files> ...` alongside an existing `tsconfig.json` produces TS5112 error.
   - Deprecated `moduleResolution=node` produces TS5107 error in TypeScript ~6.0.3.
   - **Workaround**: Added `--ignoreConfig --ignoreDeprecations 6.0` to the `dist-test` compilation command:
     ```bash
     cd mobile && npx tsc src/lib/daySchedule.ts src/lib/timetableGrouping.ts src/lib/periodUtils.ts src/lib/dataRepair.ts src/lib/dateUtils.ts src/lib/examEngine.ts src/lib/studyStreakEngine.ts src/engine/deadlineEngine.ts src/engine/cognitive-load.ts src/engine/dateHintParser.ts src/engine/sm2.ts src/engine/streak.ts src/types.ts --outDir dist-test --target es2022 --module commonjs --moduleResolution node --skipLibCheck --esModuleInterop --ignoreConfig --ignoreDeprecations 6.0
     ```

2. **Web Bundle Export Verification**:
   - Expo telemetry requires write access to `~/.expo/state.json`.
   - **Workaround**: Ran `EXPO_NO_TELEMETRY=1 npx expo export --platform web` which bundled all 1,374 modules cleanly with exit code 0.
