## 4. Key Design Choices Made in Slot Allocation

1. **Complete Purity & Isolation**:
   - `schedulerEngine.ts` does not touch React, React Native, or SQLite. It only utilizes data interfaces from `../types` and calendar parsing from `../lib/dateUtils`.
2. **Break Buffer Reservation**:
   - When a task chunk is placed in an available slot, `prefs.minBreakMinutes` is immediately added to the end time (`nextStart = endMins + minBreak`). If the slot does not have sufficient time for another minimum chunk, it is removed from that day's free slots pool. Trailing breaks that coincide with the end of the day or study window boundary do not invalidate the block placed at the slot's tail.
3. **Midnight-Crossing Window Clamping**:
   - If the study window crosses midnight (e.g. 20:00 to 01:00 where `endMinutes <= startMinutes`), the window end is cleanly clamped to `23:59` (1439 min) to preserve daily interval boundaries and prevent cross-day time bleed.
4. **Deterministic Block Identifiers**:
   - Generated study blocks use deterministic IDs (`sb-${task.id}-${blockCounter++}`), ensuring identical outputs given identical inputs and preventing test flakes.
5. **Robust `daysOff` Handling**:
   - `findFreeSlots` matches `prefs.daysOff` by exact date string (`YYYY-MM-DD`), full weekday names in English and Indonesian (`Sunday`, `Minggu`), 3-letter abbreviations (`Sun`, `Min`), and ISO numeric day indices (`0`, `7`).
6. **Alternating A/B Week Support**:
   - Timetable extraction accounts for ISO 8601 odd/even weeks when selecting active entries with `weekPattern: "A"` or `"B"`.
