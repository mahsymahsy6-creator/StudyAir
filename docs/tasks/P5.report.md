## 4. Ponytail Senior Dev Notes
- **Smallest change**: Leveraged the existing `buildSchedule()` engine from P3 directly in `CreateScheduleSheet.tsx` without intermediate wrappers. Stored 1 snapshot in `lastScheduleBackup` in React Context state for instant O(1) undo without complex undo trees.
- **Skipped**: Complex multi-level undo stack or manual drag-and-drop block re-ordering (post-pilot scope).
- **Risk**: If the user kills the app process immediately after applying a schedule, the in-memory undo buffer is discarded (the applied schedule itself remains safely persisted in SQLite).
