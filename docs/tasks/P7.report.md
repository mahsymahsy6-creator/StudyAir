# P7 Execution Report: Tugas Screen (4 Groups)

## 1. Summary
Transformed the Tugas screen into the 4-group v2 architecture conforming to Product Brief v2:
1. **Terjadwal**: Active tasks with scheduled study blocks, displaying subject dot, task title, deadline badge, and upcoming block time (`Hari ini 16:00`, `Besok 15:30`, or date).
2. **Belum dijadwalkan**: Active tasks awaiting scheduling, showing estimated duration chip (e.g. `45 mnt`).
3. **Tidak muat**: Tasks that cannot fit before deadline, highlighted with warning status pill (`Waktu kurang`).
4. **Selesai**: Completed tasks with strikethrough styling and collapsible section if > 2 items.

A prominent "Buat jadwal" banner is rendered at the top whenever unscheduled or unallocated tasks exist, opening `CreateScheduleSheet` with 1 tap. `TasksSection.tsx` was refactored to delegate cleanly to `TasksScreen`, eliminating >1,100 lines of obsolete v1 modal/quest code.
